### Session pickup

**You own the resume point. Reuse work supported by current evidence.**

Read [Task files and cleanup](task-artifacts.md). Start with an explicit archived plan/task record when supplied; reuse its archive and validate any retained scratch before resuming. Keep host transcripts with their host and write only the reduced handoff record to the archive.

1. Locate the prior trail: a Claude Code or Codex session transcript, or a pushed branch. Resolve transcript locations from the active host or user-supplied session metadata at runtime. Match the recorded working directory to the scoped project. Take the transcript the user names, or the newest one whose working directory is this repo or one of its worktrees. Do not search transcripts from other projects. Read session metadata and last messages first, then the relevant decisions. Parse long transcripts in the parent or an optional supported read-only delegate and keep the reduced timeline in the main thread.
2. Reconstruct operational state. Establish the branch, worktree, landed commits, current diff, open todos, and decisions. Use the trail for intent and history; establish current state from Git and the recorded artifact evidence.
3. Diff done vs pending against the original goal. Reuse completed work when its evidence identifies the tested artifact/source revision and environment, covers the current requirements, and remains applicable. A prior agent's completion claim alone is not evidence.
4. Verify only missing, failed, stale, or affected evidence on the real artifact. Changed requirements, source, or environment require refreshing affected coverage, not restarting the whole task. Preserve applicable results and report what was reused, rerun, or remains pending.
5. Route remaining work to the matching playbook: continue implementation, deliver a finished result, ratify or override a prior conclusion, or investigate a failed run. If the original goal is already satisfied by current evidence, report completion without repeating its work.

**Reply:** where the prior agent stopped, the resume point, evidence reused or refreshed, pending checks, and the outcome.
