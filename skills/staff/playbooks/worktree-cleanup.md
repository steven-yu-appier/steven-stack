### Worktree and simulator cleanup

**You own the inventory and the deletion gate.** Reclaim disk only from a confirmed set. A merge or stale timestamp does not prove that local data is disposable or a worktree is unused.

1. Snapshot and audit. Record `df -h /`, then run `scripts/worktree-audit.sh`. It reads NUL-delimited Git worktree paths and local refs without fetching. For current PR metadata, use `--github` outside the sandbox with escalated permissions because it invokes `gh`. Missing metadata or failed Git reads remain unknown. The script does not read chat contents or establish session usage.
2. Check usage through the host's explicit session/worktree inventory and native worker inventory. Include workers whose worktrees differ from their parent session. Do not scan global chat directories or delegate transcript searches. If an inventory cannot establish whether a candidate is in use, hold it back. `USAGE=unknown` is never deletion clearance.
3. Inspect local data. `wip:N`, `untracked:N`, and `ignored:N` all mean hold; none means throwaway. The table shows one category, so inspect the complete `git status --porcelain --untracked-files=all --ignored=matching` for each candidate. A failed read is unknown, never clean. `verify-usage` only means clean plus merge evidence, with usage still unchecked; other buckets stay held or need review. Confirm local-only commits and branch retention separately.
4. Present the exact proposed paths, merge evidence, usage checks, and any local data before deletion. Obtain confirmation for irreversible loss per Staff's Autonomy gate unless existing authorization already covers the exact targets and loss. A general cleanup request alone does not authorize discarding untracked or ignored files. Unknown or in-use paths remain held.
5. Recheck each approved path's usage and full Git status immediately before removal. If anything changed, hold it back. Use `git worktree remove <path>` without force. If removal fails, report it and retain the directory; do not bypass protection with `--force` or `rm -rf`. Re-list worktrees and record `df -h /` afterward.
6. Simulators and caches follow the same gate. Inventory specific devices, runtimes, or cache paths, establish that they are unused, and propose exact targets. Do not use blanket `delete all` commands. Remove only the confirmed set and report held items.

**Reply:** disk usage before and after, paths removed, and a reason for each held item, including unavailable usage or Git evidence.
